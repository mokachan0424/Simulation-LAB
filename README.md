# Simulation LAB

Godot 4.x で作った、中学生向けの化学学習アプリです。
原子を組み合わせて物質を作る実験シミュレーション、元素図鑑、教科書ページ、練習問題が入っています。

## できること

- 🧪 **自由実験シミュレーション**：原子21種類をドラッグで組み合わせて、物質モデル（51種類）を作れます。原子の合計が合えば、2種類以上の組み合わせでも判定されます
- 📖 **元素図鑑**：19元素の詳細ページ。反応式をタップすると、その式の組み合わせの原子が置かれた状態で実験画面が開きます
- 📚 **教科書**：5単元・10の学習項目。本文・図・ことば・実験の説明つきで、実験からシミュレーションへそのまま飛べます
- 📝 **練習問題**：単元ごとの簡易問題、少し細かい問題、テスト問題（50問）、化学反応式の問題
- 👤 **マイページ**：解いた問題の進み具合を表示します

## ファイル構成（scripts/）

| ファイル | 内容 |
|---|---|
| main.gd | メインメニューと画面の切り替え |
| user_auth.gd | 新規登録・ログイン画面 |
| mypage.gd | マイページ（学習進捗） |
| simulation.gd | 自由実験シミュレーション |
| encyclopedia.gd | 元素図鑑 |
| textbook_page.gd | 教科書ページ |
| unit_select_page.gd | 問題の選択画面 |
| practice_quiz_page.gd | 練習問題（クイズ） |
| reaction_practice_page.gd | 化学反応式の問題 |

## 動かし方

Godot 4.x のプロジェクトで、`scripts/` のファイルを `res://scripts/` に置いてください。

※このリポジトリはスクリプト一式です。シーンファイル（node_2d.tscn など）は含まれていません。
